# 📍 Verificador de CEP Local

Uma aplicação desktop simples e intuitiva feita em Python para consulta de endereços brasileiros a partir do CEP. 

O projeto utiliza uma interface gráfica e consome dados em tempo real de uma API pública.

<img width="590" height="488" alt="Captura de tela" src="https://github.com/user-attachments/assets/39011b3b-be1a-4dbd-9c22-a49e5e3c9198" />

## 🚀 Funcionalidades
* Consulta em tempo real: Busca dados de endereço atualizados através da API ViaCEP.
* Validação de entrada: Limpa traços, validando se o formato possui os 8 dígitos necessários.
* Interface Gráfica (GUI): Janela amigável desenvolvida com Tkinter.
* Tratamento de erros: Alerta o usuário caso o CEP seja inválido, inexistente ou ocorra falha de conexão.

## 🛠️ Tecnologias Utilizadas
* Python 3 (Linguagem base)
* Tkinter (Interface gráfica integrada do Python)
* Requests (Biblioteca HTTP para consumo da API)
* API ViaCEP (Serviço webservice gratuito de CEP)

## 📦 Como Executar o Projeto

### Pré-requisitos
Você precisa ter o **Python** instalado na sua máquina.

### Passo a passo

1. **Clone este repositório**:
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto**:
   ```bash
   cd Robsonhc-ti-verificador-cep-python
   ```

3. **Instale as dependências**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Execute o aplicativo**:
   ```bash
   python main.py
   ```
